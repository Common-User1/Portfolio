# Michael John J. Felices — Portfolio

Plain HTML, CSS, and JavaScript. Nothing to install.

## Open it
Double-click `index.html`.

## Finish it (5 minutes)
1. Open `index.html` in a code editor such as VS Code.
2. Search for `[` and replace each bracket with your real details: Grade Checker description, tools, skills, email, and links.
3. Save and refresh the browser.

## Change the look
`css/style.css`, section 1 (Variables). Change `--accent` for a different color.

## Add a project
Copy one `<li class="work-item no-link reveal">…</li>` block in the Projects section and edit it.

## Put it online (free)
Upload the folder to GitHub Pages, Netlify, or Cloudflare Pages.
